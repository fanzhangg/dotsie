Dotsie

Developers

Dotsie plans road trips that everyone on a trip can edit. An AI assistant can read and change people's trips through the MCP server, with their permission. This page also lists the app's own API and the places data Dotsie collects.

MCP server

What the server tells an assistant

Sign-in

OAuth 2.1. A client finds everything from the discovery documents: an assistant needs nothing but the server's address. People sign in to Dotsie and allow the assistant; it then acts as them, on the trips they're on.

Tools

As the server lists them (tools/list). Each returns JSON as structured content and as text; a mistake in the arguments comes back as a tool result with isError, saying which field is wrong.

App API

The API the Dotsie app itself uses. It's built for the app and can change with it; to work with people's trips from elsewhere, use the MCP server.

Spots data

What Wikidata and the National Park Service say about places in the US, collected each month, state by state, as the ground for Dotsie's sights: names, points, types, identifiers, page views, and links between sources. Search the spots data.

From it, a model picks each destination’s places worth a special trip and writes their guidebook entries, from the sources each lists, under CC BY-SA 4.0. Preview the guide, for review before it reaches the app.
